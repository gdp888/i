# Малахит ГЕО-4

Решение для участков с высоким уровнем грунтовых вод (УГВ) и глинистыми почвами.

Малахит ГЕО-4 разработан специально для проблемных гидрогеологических условий.

даже там, где самотёчный сброс невозможен.
