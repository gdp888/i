# Материалы (брошюры, фото, прайс)

Сюда загружаем:
- Брошюры и каталоги септиков (PDF)
- Фото установленных объектов (до/после)
- Сертификаты и лицензии
- Прайс-листы
- Инструкции по эксплуатации
- Видеоматериалы (или ссылки на YouTube)

## Папки для организации (можно создавать по мере необходимости)

- `photos/` — фото объектов
- `pdf/` — брошюры и каталоги
- `price/` — прайс-листы
- `video/` — ссылки на видео
