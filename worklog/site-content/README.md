# Контент для сайта

Сюда кладём готовый текстовый контент, который пойдёт на сайт:
- Заголовки и подзаголовки
- Описание разделов (Главная, Каталог, О компании, Услуги, Контакты, FAQ)
- Отзывы клиентов
- Описания моделей септиков
- Статьи блога (если будет)

## Структура файлов по разделам

- `home.md` — главная страница
- `catalog.md` — каталог септиков
- `services.md` — услуги (монтаж, обслуживание, шеф-монтаж)
- `about.md` — о компании
- `contacts.md` — контакты
- `faq.md` — частые вопросы
- `reviews.md` — отзывы
