# Worklog — рабочая папка проекта сайта ИТР

Эта папка предназначена для хранения материалов, контекста и рабочих заметок
по проекту сайта для дилерского бизнеса **ИТР** (продажа и установка септиков,
инженерных решений).

## Структура

| Папка            | Что сюда класть                                                          |
|------------------|--------------------------------------------------------------------------|
| `context/`       | Информация о компании ИТР, бизнес-процессах, целевой аудитории, регионах работы, УТП |
| `materials/`     | Брошюры, прайс-листы, фото объектов, сертификаты, инструкции, видео, ссылки на ресурсы |
| `site-content/`  | Готовый текстовый контент для сайта: заголовки, описания, разделы, отзывы, FAQ |
| `meetings/`      | Заметки по обсуждениям с агентом, принятые решения, TODO                 |

## Как пользоваться

1. Перед каждой новой итерацией работы над сайтом агент закидывает сюда
   свежие материалы (PDF, фото, тексты, ссылки).
2. Перед началом работы я (ассистент) читаю содержимое этой папки, чтобы
   понимать актуальный контекст.
3. После завершения очередной задачи я оставляю запись о проделанной работе
   в `/home/z/my-project/worklog.md` (локальный лог сессии).

## Формат файлов

- Текстовые материалы — `.md` (Markdown) или `.txt`.
- Изображения — `.jpg` / `.png` / `.webp`.
- Документы — `.pdf`, `.docx`, `.xlsx`.
- Ссылки и заметки — `.md` со списком URL и описанием.
